# ربات صبارسانه — نسخه‌ی کاملاً آنلاین و رایگان

بدون کامپیوتر روشن، بدون سرور و بدون کارت بانکی. یک بار نصب می‌کنید و روی زیرساخت کلادفلر همیشه روشن است.

```
تلگرام ──webhook──► Cloudflare Worker ──► فیلتر قوانین (پرسش؟ مرتبط؟ حساس؟)
                         │
                         ├─► ۱) بانک پاسخ (D1) ── پرسش تقریباً یکسان؟ ► پاسخ مستقیم (بدون AI)
                         ├─► ۲) بانک پاسخ + Gemini ► بازنویسی کوتاه از روی متن بانک   (پشتیبان: Workers AI)
                         └─► ۳) بانک جواب نداشت ► جست‌وجوی وب (Tavily، دامنه‌های معتبر) + Gemini
                                                    └─ همیشه با تأیید مدیر
```

## چرا این انتخاب‌ها
| بخش | انتخاب | دلیل |
|---|---|---|
| اجرا | Cloudflare Workers (پلن رایگان) | همیشه روشن است، به خواب نمی‌رود، کارت نمی‌خواهد. در مقابل، هاست‌های رایگان پایتون معمولاً می‌خوابند یا دیسک را پاک می‌کنند |
| دیتابیس | Cloudflare D1 (SQLite) | رایگان، ماندگار، همان مفهوم SQLite |
| هوش مصنوعی | Gemini Flash-Lite (سطح رایگان Google AI Studio) | بدون کارت، کیفیت فارسی خوب. پشتیبان: Workers AI کلادفلر |
| جست‌وجوی وب | Tavily (۱۰۰۰ اعتبار رایگان در ماه، بدون کارت) | امکان محدودکردن به دامنه‌های معتبر. |

**نکته‌ی مهم:** جست‌وجوی داخلی Gemini (Grounding with Google Search) طبق صفحه‌ی قیمت رسمی Google در سطح رایگان **در دسترس نیست**، برای همین از Tavily استفاده شد.

## محدودیت‌ها و ملاحظات صادقانه
- سطح رایگان Gemini محدودیت تعداد درخواست دارد (حدود ۱۰ تا ۱۵ درخواست در دقیقه و چند صد تا حدود هزار در روز؛ Google بدون اطلاع تغییرش می‌دهد) و **داده‌ی سطح رایگان ممکن است برای بهبود محصولات Google استفاده شود**. پس چیزی جز متن پرسش‌های عمومی گروه به آن نمی‌رود.
- برای مقیاس گروه شما (چند ده تا چند صد پرسش مرتبط در روز) کافی است؛ چون پاسخ مستقیم از بانک اصلاً AI مصرف نمی‌کند و فقط پیام‌های مرتبط بررسی می‌شوند.
- شرایط سطح رایگان همه‌ی این سرویس‌ها ممکن است عوض شود. طراحی چندلایه است تا با از کار افتادن یکی، بقیه جواب دهند.
- هیچ پاسخ گرفته‌شده از وب خودکار ارسال نمی‌شود؛ همیشه مدیر تأیید می‌کند.

## نصب (یک بار، حدود ۲۰ دقیقه)
پیش‌نیاز: حساب رایگان [Cloudflare](https://dash.cloudflare.com)، و Node.js روی یک کامپیوتر (فقط برای همین یک بار نصب).

1. **ربات:** در BotFather ربات بسازید، توکن را نگه دارید و `/setprivacy` را روی **Disable** بگذارید.
2. **کلیدهای رایگان:**
   - Gemini: از aistudio.google.com کلید API بگیرید.
   - Tavily: از tavily.com ثبت‌نام کنید و کلید بگیرید.
3. **راه‌اندازی:**
```bash
npm install
npx wrangler login
npx wrangler d1 create sabarasaneh          # database_id را در wrangler.toml جایگزین کنید
npx wrangler d1 execute sabarasaneh --remote --file=schema.sql
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET       # یک رشته‌ی تصادفی از حروف/عدد/_/-
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put TAVILY_API_KEY
npm run seed                                 # بارگذاری بانک پاسخ اولیه
npx wrangler deploy
```
4. **وب‌هوک:** آدرسی که wrangler می‌دهد را با `/setup?key=<WEBHOOK_SECRET>` در مرورگر باز کنید (باید `"ok":true` ببینید).
5. ربات را به گروه اضافه کنید (برای کامنت کانال: گروه بحثِ متصل به کانال). اگر privacy را بعد از افزودن تغییر دادید، ربات را یک بار حذف و دوباره اضافه کنید.
6. در چت خصوصی ربات `/myid` بزنید و عدد را در `ADMIN_IDS` فایل `wrangler.toml` بگذارید؛ سپس `npx wrangler deploy` دوباره. حالا `/start` بزنید تا ربات بتواند برایتان کارت تأیید بفرستد. در گروه هم `/chatid` بزنید و در صورت تمایل در `ALLOWED_CHAT_IDS` بگذارید.

ربات با **حالت آزمایشی** شروع می‌کند: هیچ پاسخی بدون تأیید شما در گروه نمی‌رود. وقتی از کیفیت راضی بودید: `/mode live`.

## تکمیل بانک پاسخ (کار اصلی شما)
هر ورودی سه چیز مهم دارد: **پرسش**، **پاسخ تأییدشده** و **منبع**. دو راه برای تکمیل:

**الف) فایل `kb/seed.json`** (برای افزودن انبوه). بعد از ویرایش: `npm run seed`
- `active: false` یعنی پیش‌نویس (ربات از آن استفاده نمی‌کند). ورودی‌هایی که هنوز `[[ ... ]]` دارند خودکار غیرفعال می‌مانند.
- `variants`: همان سؤال با عبارت‌های دیگر؛ هرچه بیشتر، پاسخ مستقیم بهتر پیدا می‌شود.
- `sensitive: true`: همیشه قبل از ارسال به تأیید مدیر می‌رود (زمان واریز، مبلغ، درصد و…).
- `kind: "ref"`: متن مرجع بلند (مثلاً متن یک ماده)؛ مستقیم ارسال نمی‌شود و فقط مبنای پاسخ AI می‌شود.
- هشدار: `npm run seed` ورودی‌هایی را که `slug` یکسان دارند بازنویسی می‌کند.

**ب) از داخل تلگرام** (بدون کامپیوتر):
```
/addfaq بازنشستگان | پرسش | پاسخ | منبع | پرسش مشابه۱ ؛ پرسش مشابه۲ | کلیدواژه‌ها
/addref قوانین | عنوان | متن کامل مرجع | منبع
/list   /show 12   /edit 12 | answer | متن جدید   /off 12   /del 12
/unanswered      ← پرسش‌هایی که جوابشان را نداشتیم؛ بهترین فهرست برای تکمیل بانک
```
همچنین در کارت تأیید، دکمه‌ی «ارسال + ذخیره در بانک» پاسخ تأییدشده را مستقیماً به بانک اضافه می‌کند؛ یعنی بانک با استفاده‌ی روزمره رشد می‌کند.

> ورودی‌های اولیه فقط تعریف‌های کلی‌اند (شستا، تأمین اجتماعی، بیمه تکمیلی، همسان‌سازی، مستمری). متن دقیق ماده ۸۹، ماده ۹۶ و موارد حساس را عمداً خالی گذاشتم (پیش‌نویس غیرفعال)؛ باید از منبع رسمی خودتان پر شود.

## دستورهای مدیر
`/status` `/auto on|off` `/mode test|live` `/web off|trusted|open` `/pending` `/unanswered` و دستورهای بانک بالا. `/help` همه را نشان می‌دهد.

- `/web trusted`: فقط دامنه‌های `TRUSTED_DOMAINS` در `wrangler.toml` (پیش‌فرض: tamin.ir، mcls.gov.ir، rc.majlis.ir، shasta.ir — **خودتان بررسی و اصلاح کنید**).
- `/web open`: کل وب (اعتماد کمتر). `/web off`: خاموش.

## تست
`npm test` — بدون اینترنت، ۱۲ سناریو (پاسخ مستقیم، حساس، عدد بی‌منبع، وب، تأیید، خاموش‌کردن و…) را اجرا می‌کند.

## نگهداری
- لاگ زنده: `npx wrangler tail`
- همه‌ی پرسش‌ها و پاسخ‌ها در جدول `qa_log` دیتابیس D1 ذخیره می‌شوند.
